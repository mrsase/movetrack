# MoveTrack — app surfaces (Overview, Items, Boxes, Labels)

**Mode:** Operate. The visitor is mid-task, one-handed, in a cluttered office.
**Audience:** the move coordinator and packing colleagues.
**Jobs:** see what is left; register an asset; pack it; move a box through its states; reprint a label; export before the laptops go.

## Direction contract

THESIS: A warehouse floor board, not a dashboard. The move is a set of physical boxes with visible states; the interface refuses the hero-metric-plus-stat-cards default and instead makes the box tiles the first object on screen.

OWN-WORLD: Concrete-grey ground, near-black ink, one hazard-yellow field carrying the brand bar and primary action. Archivo variable (wide 100–125 for the wordmark and box numbers, normal 100 for UI). Flat 1px rules, no drop shadows on content, dashed outlines for unsealed boxes, small status stamps and tinted fields as the only color in the list.

STORY: The coordinator opens the app and knows within two seconds what is still loose and which boxes are not unpacked. A colleague taps Add item, names the thing, picks a box, and is done before the tape gun runs out.

FIRST VIEWPORT: 56 px hazard bar with MOVETRACK on the left and “10 / 46 delivered” on the right. Two actions in a row (Add item solid ink, New box outlined). Then “The floor”: a two-column grid of 12 box tiles, each with a 28 px condensed box number, label, destination and item count; open boxes dashed, delivered ones tinted green with a stamp. Below the grid, a ruled list of items still in the office.

FORM: chosen 2 of 4 in the composition pass; seed: none (unavailable) — no concept roll or decision page ran in this harness, so the direction is derived from the brief and the Operate constraints, disclosed at handoff.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
